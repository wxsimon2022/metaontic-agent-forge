# 画面风格库（按创意推荐风格）

用户给出创意、但**没有指定画面风格**时读取本文件：按创意、题材、受众和交付场景挑 2–4 个合适的风格，让用户选一个，再按选定风格完善创意与脚本。用户已经说清风格（例如“真实自然”“二维动画”“国风水墨”），或明确说“你定”，就直接采用并写进脚本，不重复推荐、不重复询问。

## 怎么挑候选

- 先判断创意属于哪一类：真实生活或人物剧情、产品与商业、风景与情绪、动画与幻想、知识解释，再按这一类扩展候选。
- 候选之间要有明显区别（不要给出几个都差不多的“写实”选项），每个选项一句话说清画面特征，以及它为什么适合这条片子。
- 选项要具体、能落到提示词（“自然光写实、浅景深”比“高级感”有用），不用无法执行的形容词。
- 一次只问风格这一件事；创意方向与画面风格都要确认时，放进同一次提问，不连续弹窗。
- 用户明确要真人出镜、又选了非写实风格时说明差异；真人参考图仍按真人限制流程处理，需要转换时单独说明计费。

## 常用风格

| 风格 | 画面与提示词要点 | 适合 | 注意 |
| --- | --- | --- | --- |
| 生活写实 | 自然光、手持轻微晃动、手机或纪录片质感、皮肤与织物真实纹理、环境同期声 | 生活短剧、口播、日常记录 | 越日常越依赖动作与对白，别用空镜凑时长 |
| 电影质感 | 电影感打光与调色、浅景深、长焦压缩、平稳运镜 | 情绪故事、品牌情绪片 | 写明色彩方向（冷暖、低饱和），否则颜色容易飘 |
| 商业产品广告 | 干净背景、柔光棚拍、材质特写、干净利落的运镜 | 商品展示、开箱、卖点视频 | 不虚构功效与参数，不硬塞人物口播 |
| 二维动画（赛璐璐） | 清晰描边、平涂上色、有限动画节奏、干脆切镜 | 动画创意、科普、可爱题材 | 明确“二维动画”，避免模型混成三维 |
| 三维卡通渲染 | 圆润造型、柔软材质、卡通比例、明亮环境光 | 家庭向、儿童、轻喜剧 | 写清“三维卡通渲染”，防止渲染成写实 |
| 国风与东方美学 | 水墨晕染或工笔细节、留白构图、青绿赭石等传统色、缓慢运镜 | 传统题材、文化、节气与诗意短片 | 细节靠特写与静止构图，不要塞快切 |
| 赛博与科幻霓虹 | 霓虹反差、雨后反射、蓝紫与洋红光源、都市夜景 | 未来题材、科技感、音乐向 | 光源位置写清楚，否则颜色互相污染 |
| 复古胶片 | 胶片颗粒、轻微漏光与暗角、褪色暖调、8mm 或 16mm 质感 | 怀旧、记忆、旅行 | 颗粒别太重，容易糊掉主体 |
| 定格与手作感 | 黏土、纸板或毛毡质感、逐格位移、手工光效 | 童话、儿童、轻科普 | 动作按“逐格”描述，避开液体与复杂毛发 |
| 自然纪录 | 长焦与微距、晨昏光线、浅景深、环境音与风声 | 风景、动物、产品自然情境 | 以画面变化推进，不靠旁白煽情 |
| 扁平插画与信息图 | 矢量形状、有限配色、图标化元素、平面构图 | 知识解释、流程说明 | 成段文字交给字幕或后期，别让模型画字 |
| 像素与低多边形 | 像素颗粒或低多边形面片、复古游戏配色、固定色板 | 游戏、趣味科普 | 不与“复古胶片”“三维卡通”混用 |

这张表是候选池，不是必选清单；创意里已有风格线索时，按线索给出更具体的候选。

## 选定后怎么落地

- 把风格写进 `script.md` 的规格（画面风格），与清晰度、画幅、时长、声音同样对待；改风格须重新确认并重新审核脚本。
- 分镜与逐段提示词使用同一套风格关键词（光影、色彩、材质、镜头语言），逐段保持统一，不在续拍段悄悄换风格。
- 风格不替代参数：480P/720P 仍按用户确认值传，不用“高清、4K、电影级”改写实际清晰度。
- 参考图风格与所选风格不一致时先说明（例如写实参考图配二维动画风格），按需要走真人限制流程后再生成。
- 实际成片与选定风格明显不符（或段与段之间像两条片子）时如实说明，给出改稿或重做的选项，不重复提交付费任务。
