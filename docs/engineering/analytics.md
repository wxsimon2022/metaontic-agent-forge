# 插件统计实现与边界

插件在后台向服务端 `/api/v1/analytics/events` 发送白名单事件；控制台 `/admin/#/plugin-analytics` 通过登录后接口查看聚合与设备列表。服务端代码位于独立的 MetaOnticVideoService 仓库。

## 不影响创作

工具入口不等待网络、身份文件或上报结果；异常不改变工具结果与错误。队列最多 200 条，每批 20 条，默认延迟 1 秒发送，请求 1.5 秒超时，每条最多尝试 3 次。定时器不阻止退出，卸载取消请求并丢弃队列，不等待补发。设置页「高级设置 → 使用统计」可关闭；开发验证可设置 `METAONTIC_AGENT_FORGE_ANALYTICS_DISABLED=1`。

## 字段与统计口径

仅接收插件启用、工具开始/完成、视频任务创建/终态事件，以及固定枚举的工具、模式、状态、错误类型和调用耗时。附系统类型、内核版本、CPU 架构、取整内存、Harness 与插件版本。不包含对话、创意、提示词、媒体、API 密钥、用户名、MAC 或序列号。安装标识是本地随机 UUID，服务端仅存其 SHA-256；任务 ID 仅参与本地散列，不上传原值。首次成功接收代表首次启用，不是下载量或人数；关闭统计、旧插件、离线或丢弃事件都会使数据不完整。

服务端按安装标识与事件 ID 幂等入库，限制请求体和 IP 频率，统计接口要求控制台登录。原始事件默认保留 90 天，首次启用记录保留；请求日志仅记录事件数。按北京时间聚合，视频任务数依据创建事件，终态重复查询不重复计数；调用耗时不是上游纯生成耗时。

## 平台与验证

Windows/macOS 共用 `node:os`、`node:path` 与随机标识实现，状态位于宿主数据目录，不硬编码开发机路径。插件新增 5 项测试覆盖白名单、掉线/超时/重试、队列上限、禁用、退出、热加载去重和工具失败隔离；独立服务端新增 12 项测试覆盖幂等、并发、鉴权、校验、限频和时区。服务端完整 188 项测试、前端构建及检查通过；插件完整 411 项测试通过。尚未由这些自动测试覆盖 Windows 桌面实测或真实付费生成。
