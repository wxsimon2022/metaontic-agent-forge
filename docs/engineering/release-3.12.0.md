# v3.12.0 发布核对

MetaOnticVideo v3.12.0（正式版）

新增
- 纯文生视频先询问是否生成角色参考图，明确图片单独计费；同意后使用Seedream按文字生成，展示审核通过才用于首段及续拍，拒绝则保留纯文生方案。
- 续拍持续携带最初角色参考图，支持明确指定角色图并默认沿用首段参考图或首帧；归一化结果随断点保存，后续分段及恢复继续使用同一套图。

优化
- 角色图转换经同意、结果审核并成功重试后，后续续拍复用获审转换图，不重复出图；已提交任务保留原请求，避免恢复时重复提交。
- 同步中英文说明、角色图选择与审核步骤、安装排查及第三方许可声明。

修复
- 宿主入口内置schemastery及其运行依赖，成品包不再依赖外部node_modules，修复卸载重装或在线更新后缺少Schema依赖导致插件启动失败的问题。
- 图片付费确认异常时停止出图；火山直连明确提示当前图片通道限制，不错误承诺可生成角色图。

验证
- 构建、211项测试与实际Harness全部9个工具输出Schema校验通过。
- 无node_modules空目录独立导入、Config校验与工具注册通过；实际Harness Schema解析器兼容验证通过。
- 模拟三种接入的60秒四段参考图传递、首帧转参考图、暂停恢复、获审转换图复用与角色图生成后用于视频链路。
- 角色图生成不带原图、使用正确图片Key、需付费确认及结果审核；查询原图片任务不重复生成。
- 使用说明书Markdown/PDF及中英文文档同步入包；App自带pnpm严格安装空白目录验证；未发起新的付费生成。
- 价格参考与实际项目素材仅留本地，未纳入仓库或发布包。

适用版本：v3.12.0。覆盖v3.11.4后全部角色图与安装稳定性改动。指南核对角色图选择、单独计费、图片展示审核、首段/续拍与恢复、纯文生分支及启动失败排查；仅MetaOntic AI用户路线，无版本号、更新内容或发布核对记录，7张配图继续适用，PDF同步。本机仅将HMR base切至已安装目录，密钥及其他配置未变，环境修复不写入发布配置。成品自包含且无外部运行依赖，许可证随包提供。
