# v3.12.1 发布核对

MetaOnticVideo v3.12.1（正式版）

修复
- 纯文生视频在提交前强制询问角色图方案，不再仅依赖助手提示词；未回答、取消、交互不可用或记录失败时停止提交，不默认跳过。
- 用户选择先生成角色图时停止纯文生请求并转入出图及审核；选择直接文生后才继续原视频费用与制作确认。

优化
- 同一会话和脚本规格保留明确选择，重复尝试不重复询问；已有参考图和断点恢复不重问，不改动或重提已提交任务。
- 同步使用说明书、PDF及内置操作规则，明确角色图选择与视频制作确认的先后关系。

验证
- 构建、223项测试及实际Harness全部9个工具Schema校验通过。
- 覆盖两项选择、空答复/取消/交互缺失、选择持久化与不同项目隔离、已有图片及恢复跳过询问。
- 实际preflight模拟确认先出角色图时视频和图片均未被自动提交；后续仅按明确选择推进。
- 自包含入口无node_modules加载、实际Harness配置Schema兼容、严格成品安装验证通过；说明书Markdown/PDF同步入包。
- 未发起付费生成，未停止或重提用户已有任务；价格参考和实际项目素材不入仓库或发布包。

适用版本：v3.12.1。覆盖v3.12.0后角色图选择缺失修复。实际任务记录证明旧版只加了提示词却未强制选择；新增提交前原生问答与选择持久化。指南核对角色图选择、生成/直接文生分支、费用审批及恢复，不含版本号/更新内容/发布核对；7张既有配图适用。Windows原生界面尚未进行实机验证。
