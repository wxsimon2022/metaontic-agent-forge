# v3.11.1 发布核对

MetaOnticVideo v3.11.1（正式版）

新增
- 阶段耗时日志，记录插件调用、轮询、下载、探测、接缝处理、合并及费用查询；脚本、示意图和审核等待独立标记，便于定位慢点。

优化
- 移除插件设置和配置工具中的全局“续拍方式”，改由已审核脚本及本次生成/续拍参数决定连续镜头、切镜和景别。
- 规范分镜图实际展示：确认文件存在，登记后在正文内嵌图片并提供原图链接；无法内嵌时如实说明，用户未见图时先补展示。
- 所有成果在正文提供可点击链接，覆盖脚本、示意图、转换图片、分段与合并视频、任务查询和恢复交付；有文件卡片仍保留链接。

- 交付顺序调整为合并后完整视频优先，其后依次展示各分段；暂停或合并失败时只展示真实已有成果。

修复
- 服务端领 Key 与手填 Key 共用中转默认地址、模型与协议；界面和配置工具保存时原子补齐连接字段，运行端兼容旧配置缺地址，保留各渠道及图片/视频 Key 隔离。
- 火山直连切回中转时恢复中转请求路径，避免沿用直连地址与路径。
- 新任务不再受旧配置残留 mode 影响；续做保留记录中的续拍方式、过渡描述与已提交原请求，避免设置覆盖脚本。

验证
- 构建、187 项测试与实际 Harness 全部 9 个工具输出 Schema 校验通过。
- 模拟落盘并重新读取，验证三种接入方式切换、地址/路径/模型补全与 Key 隔离；验证脚本续拍参数及暂停恢复。
- 覆盖转换图片、单段与多段视频、部分完成、失败恢复及状态查询的可点击链接。
- 使用说明书 Markdown/PDF 已同步并纳入插件包；成品包通过 App 自带 pnpm 严格构建脚本策略安装验证。
- 未发起新的付费生成；价格参考及项目素材仅留本地。

适用版本：v3.11.1。覆盖 v3.11.0 后全部未发布调整。指南逐项核对配置、脚本审核、续拍过渡、图片展示、文件链接、恢复及交付；仅使用 MetaOntic AI 用户路线，不包含版本号、更新内容或发布核对记录。六张配图未涉及已移除的续拍选项，继续适用；PDF重新导出。发布包检查排除价格参考与实际项目素材。
