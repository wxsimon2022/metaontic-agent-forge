# v3.11.2 发布核对

MetaOnticVideo v3.11.2（正式版）

优化
- 脚本费用明细逐段展示无视频/有视频输入档位、输入与输出秒数、单价和金额，方便核对续拍费用。

修复
- 续拍估价计入上一段完整视频输入，首段使用无视频输入单价，后续使用有视频输入单价；参考图和首尾帧不再误用含视频输入单价。
- 统一脚本估价与制作确认口径，校准480P估算尺寸；恢复时读取上一段视频时长，外部视频时长未知时明确无法可靠估价。
- 脚本审核新增分镜展示检查：present登记后还须在独立正文内嵌同版图片，缺失时拦截审核并提示补展示；内部看图、文字描述及上一轮旧图不能代替本轮展示。

验证
- 构建、200项测试及实际Harness全部9个工具输出Schema校验通过。
- 以真实会话记录回放：present后直接提审核被拦截，补正文图片后放行；测试覆盖版本/轮次/会话隔离及普通问题不受影响。
- 模拟验证480P/720P脚本与制作估价一致、续拍输入时长与单价正确、恢复保留输入时长；未发起付费生成。
- 使用说明书Markdown/PDF同步并纳入插件包；空白目录使用App自带pnpm严格策略安装验证，无esbuild运行依赖。
- 价格参考、比价方案及实际项目素材仅留本地，不纳入仓库或发布包。

适用版本：v3.11.2。核对从v3.11.1之后的全部改动：续拍输入计费、估算尺寸、逐段明细、恢复与外部素材时长、分镜审核展示检查。指南仅面向MetaOntic AI使用路线，不包含版本号、更新内容或发布核对记录；配图未涉及本次变化，六张继续适用，PDF同步重新导出。展示检查使用插件加载后的实时会话事件，既有审核窗口不追溯改变；未核实的旧图不能作为本轮展示证明。
