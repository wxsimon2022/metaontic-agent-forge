# v3.13.4 发布核对

实际基线：v3.13.3。

MetaOnticVideo v3.13.4

优化
- Windows 安装教程第 3、4 步补充“安装框要文件路径、不要文件夹路径”，常见问题新增“提示不是有效的插件包”条目；使用说明书 1.3 节同步更新并重新导出 PDF。

修复
- 修正 Windows 安装指引。安装框要填 .tgz 成品文件路径，填入解压后的 MetaOnticVideo-Windows 外层文件夹或 package 资料目录会提示“不是有效的插件包”；现在压缩包教程、使用说明书与 README 都写明这一点，并在常见问题给出该提示的排查方法。
- Gitee 附件上传超时由 60 秒延长到 5 分钟，并在上传超时后复查附件是否已存在且大小一致，避免 Windows ZIP 等较大成品被误判为发布失败、导致镜像发布页缺少附件。

验证
- 本地构建及测试通过。
- Windows/macOS成品安装及升级为CI上传前置条件。
- 桌面GUI与付费调用未由发布脚本自动验证。

指南核对：本次改动集中在 Windows 安装指引。逐项核对使用说明书 1.2 在线安装、1.3 Windows 本地安装、1.4 Mac 本地安装、1.6 安装是否成功及第 5 节排错：1.3 节新增“安装框要填文件不是文件夹，填入 MetaOnticVideo-Windows 外层文件夹或 package 资料目录会提示不是有效的插件包”的说明，步骤、默认行为与其余 FAQ 未变；安装配图仍为原有 7 张、操作位置未变，无需重绘。说明书不含版本号、更新内容或发布信息，Markdown 与 PDF 已同步重新导出并核对，确认纳入插件包。
