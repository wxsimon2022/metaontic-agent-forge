# v3.13.15 发布核对

实际基线：v3.13.14。

MetaOnticVideo v3.13.15

优化
- 生成结果里成片行排在分段逐条列表之前，工具结果卡片与交付清单统一先看成片、再看分段。
- 正式版以 Gitee 发布页为主，成品在本地打包后直接上传，发版不再等 GitHub Actions 回传；在线安装与在线更新继续同时查询 Gitee 与 GitHub，两边发布不同步时也能取到新版本。

修复
- 成片被改名或换目录后交付顺序卡口失效——助手把成片另存成别的文件名（例如 final/<项目名>-60s.mp4）、或把分段换成交付目录里的 15 秒副本时，插件认不出这两类文件，分段就排到了成片前面；现在按绝对路径、同名、文件字节数逐级认领，成片排在分段或上一版中间合并视频之后一律拦下并要求把成片放第一位重发。

验证
- 本地构建及测试通过。
- 本条按仅 Gitee 发布处理：未运行 GitHub 双平台 CI，也没做 Windows 桌面实测，Windows 兼容性只有构建与打包层面的保证。
- 桌面GUI与付费调用未由发布脚本自动验证。

指南核对：本次涉及第 1 节在线安装的第 78/81 行两条成品地址，已同步改为 v3.13.15，并补写「正式版以 Gitee 发布页为主、GitHub 同步可能较晚，找不到该版本时用 Gitee 地址」；第 6 节成片展示段（原第 254 行）补写「成片改名或换到 final 等目录同样按成片判定，不会因改名放过顺序错误」，与新的卡口行为一致。其余章节（安装与卸载、设置页配置、脚本与分镜审核、费用预估与计费、长视频与中断恢复、故障排查、动画与配音）逐条复核，与当前版本一致、无过时说明；指南不含版本号、适用版本、更新日志与发布核对记录，正文修改后已重新导出 PDF，7 张配图解码正常，Markdown 与 PDF 内容一致并随包发布。
