# 无限画布接入

## 上游与分发

固定 Haitang-Hub/dsh-infinite-canvas 0.2.9，提交 `0a8a8dccc8e8d4fcaa0d792750a8d45be8e5def8`。`vendor/infinite-canvas/` 保留桥、站点与 MIT 许可，`UPSTREAM.json` 记录来源和适配文件哈希。不依赖运行时下载、npm 开发依赖或单独安装画布；不包含 NINKCH 的另一套同名项目。

`scripts/adapt-infinite-canvas.mjs` 对固定上游的明确位置做适配，找不到唯一位置立即失败，运行两次应幂等。修改后的内容在清单中登记；升级上游时须重新核对桥协议和浏览器执行器。

## 调用链

平台客户端注册独立右侧标签「创作画布」。首次打开通过宿主鉴权连接端点启动托管桥，iframe 加载本包自带站点。Agent 使用 `metaontic_agent_forge_canvas`，经本机桥 `/api/tools`、SSE 执行器操作真实上游节点，不自行绘制替代品。

总控 open 用会话 ID 与业务 projectId 派生 canvasId，并将其传给专业助手。其他动作必须提供原 canvasId。桥在投递前比对 projectId，浏览器执行编辑前再次比对，防止排队时用户切换画布导致误写。open 只表示请求打开，不表示编辑已完成；读取或编辑须等实际执行器上线，未就绪返回错误。新请求可重新聚焦已经关闭的相同项目标签。

桥数据独立保存在宿主 HOME 下 `metaontic-agent-forge/canvas`（支持 DSH_HOME）。项目 store 通过同源 KV 路由原子写盘；媒体复制到私有目录后预览，源文件不删除。路径和进程均用 Node API；启动不使用 shell，Electron 设置 Node 模式，环境剔除凭据；停用/HMR 只终止本插件创建的子进程，不接管占用端口的未知进程。数据保留。端口默认17379，可通过 METAONTIC_AGENT_FORGE_CANVAS_PORT 调整。

## 制作与审核

站点原有模型配置、AI助手和生成配置入口不向用户提供；保留内部画布执行器所需的隐藏组件。浏览器 CSP 仅允许同源连接，桥不开放代理、模型或独立 Agent 执行接口。工具入口只允许读取和普通节点编辑，禁止 run_generation 及其工具变体。画布不接收插件 API密钥，不迁移上游渠道配置。

媒体导入先检查目标画布，再复制已存在的本地图片/视频，返回可连线的稳定节点ID。失败不触发生成；重复导入沿用节点。脚本、费用、逐段结果审核和恢复仍由现有视频业务完成。画布不是审核事实来源，任务关系图仍展示真实会话状态。
