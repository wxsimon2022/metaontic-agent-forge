# v3.13.10 发布核对

实际基线：v3.13.9。

MetaOnticVideo v3.13.10

新增
- 新增测试包分发通道，在仓库执行 `npm run pack:test -- 版本号-后缀` 就会自动构建、运行单元测试、打出测试版 `.tgz`、上传到 `https://video.mybfs.cn/test/`，并核对线上文件与本地 sha256 一致后输出可直接转发的安装地址，未发布的改动可以先给他人试用。

优化
- 测试包不占正式发布页，只改包内版本号，不提交、不打标签、不建 Release，核心版本号压在当前正式版之下，其他人仍会正常收到正式版更新提示；脚本结束后把包内版本号与构建产物还原为正式版本，不会把测试版本带进正式包。
- README 发布章节与工程维护经验补充测试包通道的用法、线上目录和回退方式；`/test/` 目录禁止缓存与搜索引擎收录，测试者用正式版 `.tgz` 地址重装即可回到正式版。

验证
- 本地构建及测试通过。
- Windows/macOS成品安装及升级为CI上传前置条件。
- 桌面GUI与付费调用未由发布脚本自动验证。
