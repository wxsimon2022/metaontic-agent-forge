# v3.13.7 发布核对

实际基线：v3.13.6。

MetaOnticVideo v3.13.7

优化
- Gitee 流水线补全为完整的构建校验：向 master 推送、发起面向 master 的 PR 或推送标签时，自动准备环境、安装依赖、执行构建与单元测试，并把 tgz 与 Windows 成品包放进流水线制品供下载核对。
- Gitee 构建机不再依赖预装环境：Node 20 由流水线自行下载（老镜像自动改用 glibc 兼容版），Windows 成品包所需的 Python 3 也会按需安装；缺失时日志给出明确提示，不再静默跳过。
- Gitee 流水线按标签运行时核对标签与包内版本是否一致，不一致立即失败，保证成品与标签对应；同时新增 ci- 开头的演练标签，可随时验证按标签运行的流程，演练不产生发布件。

验证
- 本地构建及测试通过。
- Windows/macOS成品安装及升级为CI上传前置条件。
- 桌面GUI与付费调用未由发布脚本自动验证。

指南核对：本次仅调整 Gitee 流水线与发布流程，未改动插件的配置项、操作步骤、默认行为与常见问题；逐项核对《MetaOnticVideo使用说明书.md》正文与配图后确认无需修改，Markdown 与 PDF 内容一致并随包发布，因此本次未重新导出 PDF。
