# 移除插件服务端接入

插件仅保留 MetaOntic AI 和已有的火山直连配置支持，默认 MetaOntic AI。移除邮箱登录、取回密钥、设备同步、账户额度、使用记录、钱包与充值代码和说明，独立服务端项目保留。

旧渠道密钥不迁移为其他渠道密钥。旧接入值须在设置页重新选择接入并填写对应 API密钥；保存时清空旧凭据。暂停任务仍受连接快照检查约束，不自动重提。

Windows/macOS 使用相同配置、界面和请求代码，无新增平台路径或外部进程逻辑。已执行本机构建、模拟接口和现有自动回归；未执行 Windows 或 macOS Harness 桌面实机操作、真实付费调用。未发布、未修改版本或 releaseNotes。
