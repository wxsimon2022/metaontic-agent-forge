# v3.13.13 发布核对

实际基线：v3.13.12。

MetaOnticVideo v3.13.13

优化
- 命中上面这条报错时不再直接放弃——更新会等后台清理完成自动重试，用户不用自己数着秒再点一次；仍然失败才提示手动删除锁文件。中英文提示同步改为「每 2 秒自动清理 + 自动重试」。
- 使用说明书、README 与工程规范同步这次排查结论与处理方式：说明该报错与插件包、操作系统无关，不是 Windows 文件占用问题，先等自动清理与重试，仍失败再完全退出 Harness 删除安装目录下的 pnpm-lock.yaml 后重装；说明书配图与 PDF 已随正文重新导出。

修复
- Windows 在线更新反复失败、报 ERR_PNPM_MISSING_TARBALL_INTEGRITY 的问题。安装目录的 pnpm-lock.yaml 里只要留着一条本插件缺少校验值的远程包记录（包括旧版本留下的、已经没人引用的记录），pnpm 就会拒绝整次安装。插件现在按「本插件所有远程记录里哪些拿不到合法校验值」来判断，profile 根目录、下级目录与同级的临时 staging 目录里的锁文件都会检查，检查间隔由 10 秒缩短到 2 秒，坏记录连同依赖声明一起清掉、其他依赖和带校验值的正常记录不动，改前文件另存为 pnpm-lock.yaml.metaontic-backup-时间。

验证
- 本地构建及测试通过。
- Windows/macOS成品安装及升级为CI上传前置条件。
- 桌面GUI与付费调用未由发布脚本自动验证。
