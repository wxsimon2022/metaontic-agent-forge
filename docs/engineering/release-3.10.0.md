# v3.10.0 发布核对

MetaOnticVideo v3.10.0（正式版）

新增
- 插件版本卡片支持最近 3 个正式版本切换，按版本号排序去重，高版本显示更新、低版本显示降级，二次确认后才安装。

优化
- 移除预发布入口，后续仅发布正式版；过滤草稿与预发布，检查更新不默认选中更低版本。
- 配置保存等待设备同步及自动取回 Key 完成，冲突时绑定修订号安全重试，保留保存期间继续编辑的输入。
- 保存失败区分配置冲突、只读、页面失效及连接中断，增加不含密钥与字段值的诊断信息。
- 在线更新安装对应 Release 成品包，Gitee 不可用时尝试同版 GitHub 附件，不回退旧版或默认分支、不先卸载插件；同步使用说明书与 PDF。

修复
- 实际费用可空字段改用宿主支持的 Schema，解决“组件启动失败”导致插件无法加载。
- 移除公共插件对 Hyperframes、esbuild 等构建工具的运行依赖，解决在线更新因安装脚本被拦截而报错。
- 重置后先核对配置并引导登录或填写 Key，保留脚本与任务进度，避免误建议重装或重启。

验证
- 构建、146 项测试与实际 Harness 的全部 8 个工具输出 Schema 校验通过。
- 使用 App 自带 pnpm 11.28.5 严格拦截构建脚本验证，正式版成品包安装成功，运行依赖不含 Hyperframes/esbuild。
- 最近三个版本选择及二次确认通过模拟界面验证，Markdown/PDF 使用说明书同步并纳入插件包；价格参考文档及宣传素材未纳入。
- 未进行新的付费视频生成，历史版本回退仍保留该版本原有行为与依赖。

适用版本：v3.10.0。以最近正式版 v3.9.0 为基线，汇总 beta.1、beta.2 及最近三版切换的最终改动；移除被取代的预发布渠道方案。逐项核对指南的安装、Key 配置、保存失败、480P/720P、脚本/恢复、费用预估/实际费用、最近三个版本切换。正文和配图不加入版本号或发布记录，PDF 同步；价格参考资料仅留本地。
