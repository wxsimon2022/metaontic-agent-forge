# v3.13.14 发布核对

MetaOnticVideo v3.13.14

修复
- 每段生成后的“继续确认”接回续做入口——点“继续”后、提交下一段之前由插件弹一次确认框，写明第几段已经生成好、接下来做第几段、整条还差多少秒和剩余分段的预估费用，同一份进度始终只弹一个确认框。“拒绝”即停止并保留已完成分段，之后仍可用 resume 续做；此前这一步只在提示词里要求助手自己询问，助手不问就会继续往下生成，插件拦不住。

指南核对：本次涉及第 8 节「长视频与中断恢复」：补充说明说“继续”后、提交下一段之前会先弹一次确认框，写明第几段已经生成好、接下来做第几段、整条还差多少秒和大概还要花多少，点“允许”才继续、点“拒绝”就先停下且已生成分段不用重做、之后随时能接着做；常见问题表「只生成第一段」一行同步改为先预览本次成果、再在确认框里点“允许”从暂停进度继续。第 1.3 节 Gitee 与 GitHub 两条成品地址同步更新为本版本 v3.13.14。其余章节（安装、设置、脚本与分镜审核、费用预估、交付顺序、故障排查、动画与配音）逐条复核，与当前版本一致、无过时说明；指南不含版本号、适用版本、更新日志与发布核对记录，正文修改后已重新导出 PDF，Markdown 与 PDF 内容一致并随包发布。
