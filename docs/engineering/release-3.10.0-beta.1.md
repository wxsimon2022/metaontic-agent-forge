# 3.10.0-beta.1 发布核对

MetaOnticVideo v3.10.0-beta.1（预发布）

新增
- 插件版本卡片支持切换正式版与预发布版渠道，确认后安装对应发布标签，并支持切回正式版。
- 发布默认采用 beta 预发布版本，增加版本号与预发布标记校验，双仓同步发布渠道。

优化
- 配置保存等待设备同步及自动取回 Key 完成，冲突时绑定修订号安全重试，保留保存期间继续编辑的输入。
- 保存失败区分配置冲突、只读、页面失效及连接中断，增加不含密钥与字段值的诊断信息。
- 更新缓存按渠道隔离，切换后忽略旧查询结果，安装不回退默认分支、不先卸载插件；同步使用说明书与 PDF。

修复
- 实际费用可空字段改用宿主支持的 Schema，解决“组件启动失败”导致插件无法加载。
- 重置后先核对配置并引导登录或填写 Key，保留脚本与任务进度，避免误建议重装或重启。

验证
- 构建、141 项测试、打包清单及实际 Harness 的全部 8 个工具输出 Schema 校验通过。
- 使用说明书 Markdown/PDF 已同步，六张配图已核对，未纳入价格参考文档及宣传素材。
- 未进行新的付费视频生成；预发布功能仍需实际使用验证。

适用版本：3.10.0-beta.1。逐项核对说明书的安装、MetaOntic AI Key 配置、保存失败处理、脚本与任务恢复、480P/720P、费用预估及实际费用展示。新增渠道切换使用步骤，保留旧安装配图（操作仍适用）；正文和配图不加入版本更新或发布记录。PDF 同步核对，价格参考及宣传资料仅留本地。
