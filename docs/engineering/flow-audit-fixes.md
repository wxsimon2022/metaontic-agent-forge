# 流程检查修订

- 明确失败、未进入真人恢复的分段允许重建本次已审核请求及角色参考图；pending、查询不明、转换/重试状态保留原请求。防重与项目审核继续生效。
- tools/pre-execute 注册未成功时，已注册的付费工具在执行入口拒绝，不能仅记录告警后继续。
- metaontic_agent_forge_video_extend 的 duration 为每段新增秒数；审核、估价、执行共用上限校验，45秒须明确安排为合法的多段计划，不能静默压为30秒。
- 制作确认只由视频工具付费审批承担，不额外询问开始制作；审核前准备完整提示词，审核后不补改。
- 目标时长为对话中的制作需求，变更后重审，不能引导到没有对应字段的设置页。
- 合并和单段交付副本均先写临时文件，成功后 rename，不先删除已有成片；失败保留原片与分段。
- 完整创意也先确认是否完善；只补原意细节。原需求已写明的时长、画幅、分辨率直接沿用，仅问缺失项，与完善选择同轮询问。

## 验证与平台影响

构建、400项自动测试、实际Harness的9个工具输出Schema检查通过；无付费API调用。故障回归覆盖确认卡口注册失败、失败分段换新提示词、续拍超限审核与合法多段、合并失败保留旧成片。历史查询和转换恢复沿用现有用例。

Windows与macOS共用node:path、临时文件和rename实现。Windows占用导致替换失败时不删除旧文件；本轮未进行Windows桌面实测，也未进行真实付费视频全流程验证。本地安装不代表已经验证用户会话中的实际弹窗。
