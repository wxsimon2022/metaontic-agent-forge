# 用户文案核对

核对范围：设置页及侧栏中英文、工具描述/参数/结果、脚本与分段确认、异常与恢复提示、动态操作规则、内置视频技能、README当前使用说明和用户指南。历史发布日志保留，不改写既有版本记录。

已修正：

- 生成成功、下载完成、合并完成和交付完成按实际证据分别表述。查询成功只代表上游本段成功，不代表本地处理完成。
- 下载前的部分成功说明不再声称已下载合并交付；暂停文件不称完整成片。下载或合并失败保留具体原因。
- 超时或查询失败不推断任务终态；401称鉴权异常，不猜测为密钥抖动。后续查询成功时报告当前结果。
- 续做复用已有成果，新增剩余分段仍需确认费用并计费；并发锁拦截说明未新增任务，不声称已发生重复扣费。
- “自动续拍”改为每段预览确认后继续，全部完成后合并；只返回上游链接时不承诺本地文件。
- 上游链接有效期由渠道决定，不保证24小时；FFmpeg安装后使用原进度恢复已有成果，避免“重跑生成”歧义。
- 删除设置页残留的MetaOntic Agent Forge接入名称；说明图片创建及经同意转换两种用途，避免误解为必须先转换真人图。
- 更新入口不可用时保留配置并参考成品包更新，不引导先卸载。中英文对应说明同步。

验证：构建与355项自动回归通过，包含暂停/交付失败/查询超时/状态成功的文案检查；本机真实宿主输出Schema校验9工具通过。无付费调用，无发布。文案改动不新增平台接口，路径与安装行为不变；未进行Windows或macOS真实桌面逐页验收。

第二轮交叉复核：移除用户指南遗留的邮箱登录/余额充值整节、登录状态及登录表单说明；标准模式话题范围与视频创作助手区分。统一底层FFmpeg缺失、安装审批、安装结果及指南的恢复措辞，不承诺安装后自动付费生成或缺失文件齐全。续做改剧情/加长需先重审，任务ID引用上游分段而非本地合并成片。再次扫描后未发现同类明显矛盾；不将人工文案审阅视为所有真实场景均已桌面验证。
