# v3.13.0 发布核对

适用版本：v3.13.0正式版。最近实际发布为v3.12.0；包含已提交但未正式发布的v3.12.1角色图选择校验及其后全部待发布改动。

## 变化范围

- 真人写实文生角色图，characterType枚举和风格建议排第一；默认保持stylized，明确选择后才使用realistic。
- 费用审批明确角色类型；真人限制转换不允许realistic，不改变单次视频重试和图片审核流程。
- 纯文生角色图选择提交前强制校验、持久化与恢复隔离，未答和不可交互时不提交。
- Windows ZIP成品与离线图文教程、PDF；GitHub/Gitee同时上传tgz、ZIP及其校验文件。
- 双平台说明书同步Mac仓库安装、Windows成品包、本地绝对路径、Key配置、在线更新与故障排查。说明书及7张配图不包含插件版本、发布说明或核对记录。
- 宣传页已在独立服务项目上线Mac/Windows安装切换，本插件不包含该站点代码。
