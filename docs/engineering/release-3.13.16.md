# v3.13.16 发布核对

实际基线：v3.13.15。

MetaOnticVideo v3.13.16

新增
- 生成进度卡片新增装饰动效——进度条上有一条跟着进度从左往右爬的小乌龟（头朝右），执行中进度框带呼吸灯边框；两者只表示“还在生成”，不代表上游真实完成比例。

优化
- 分段下载与分段探测改为并发执行（上限 4 路），长视频收尾更快；结果仍按段号顺序处理，下载失败仍按最靠前的那一段报错，已下好的分段照样记进结果。
- 服务端模式的使用记录卡片暂时隐藏——设置页不再显示「使用记录」，后台也不再轮询记录接口，额度卡片与其余设置不受影响，恢复时改一个开关即可。
- 参考图适配缓存自动清理（超过 7 天或超过 200 个时从最旧的删起，正在写入的临时文件不动），长时间使用不再把系统临时目录撑满。
- video_generate 与 video_extend 的分段收尾（结果落盘、中断收尾、暂停提示、merge:false、下载合并交付）合并成同一套实现，两处措辞只维护一份；暂停时「还剩多少秒」统一按计划总时长扣减已完成分段。
- 日志目录按天缓存创建结果，创建失败不缓存以便下次重试；清理只在本模块内使用的内部导出，插件对外接口更收敛。

修复
- 15 秒以上视频交付时成片没有排在第一位——宿主交付卡片按本轮文件首次出现的顺序排列、按路径去重、超过 4 条还会折叠，中途登记的脚本、分镜图、参考图、单段预览和部分合并都会把成片挤到后面，事后补发也挪不回来；现在交付卡片只登记「最终成片 + 各分段」，成片固定在第一个位置，暂停、部分交付或还在等待查询时不再登记卡片，成片排在分段之后、漏掉成片或带上中间版本成片都会被拦下并按提示重发。
- 脚本审核窗口偶发不弹——助手把展示脚本的正文单独发成一条消息后直接结束本轮，审核提问没有发出；现在正文展示与审核提问不再拆成两轮，脚本保存为 script.md 时插件自动收口脚本设计耗时，展示完正文紧接着提问，仍在展示后结束回合会记录留痕以便定位。
- 分镜图审核只认正文内嵌——present 登记不再算用户看到了图，模型看图与文字描述也不算；改稿后同目录里还有比已内嵌那张更新的分镜图时同样拦下并提示补展示本版图片。

验证
- 本地构建及测试通过。
- 本条按仅 Gitee 发布处理：未运行 GitHub 双平台 CI，也没做 Windows 桌面实测，Windows 兼容性只有构建与打包层面的保证。
- 桌面GUI与付费调用未由发布脚本自动验证。
