# v3.11.0 发布核对

MetaOnticVideo v3.11.0（正式版）

新增
- 续拍支持过渡画面描述，随脚本审核并传入视频请求；逐段描述优先于通用描述，暂停续做沿用已确认内容。
- 完善脚本与逐段提示词：统一主体标签，按分镜顺序描述动作、场景和镜头，并明确光影、风格、画质及约束条件。

优化
- 多段视频逐项交付第一段、第二段及后续全部分段，并单独展示真实合并成片；暂停或合并失败时仍交付已完成分段。
- 移除版本选择和降级入口，仅保留检查更新及二次确认更新到更高的最新正式版。
- MetaOntic AI 接入显示专用 Key 配置提示，并提供 ai.bileego.com 注册获取 Key 的链接；同步使用说明书与 PDF。

修复
- 明确过渡安排切镜时，取消接缝处相同机位、景别和焦段的冲突约束；自动提示词直接使用“视频1”指代延长素材。
- 过渡描述持久化到断点，非法描述在提交前拒绝；不向上游添加不支持的参数，不因应用新描述重复提交已有任务。

验证
- 构建、164 项测试和实际 Harness 的全部 8 个工具输出 Schema 校验通过。
- 使用 App 自带 pnpm 严格拦截构建脚本验证，成品包安装成功，运行依赖不含 Hyperframes/esbuild。
- 模拟接口覆盖三个接入渠道的过渡描述、暂停续做和提交前校验；更新入口及 MetaOntic AI 注册链接通过真实组件模拟界面验证。
- 使用说明书 Markdown/PDF 已同步纳入包，六张配图仍适用；价格参考文档及宣传素材未纳入。
- 未发起新的付费视频生成，不保证完全消除接缝跳变，成片效果仍需实际预览验收。

适用版本：v3.11.0。核对范围为 v3.10.0 之后全部改动。已逐项检查指南中的 MetaOntic AI 注册/Key、配置保存、仅更新至最新正式版、过渡描述审核与续做、逐段和合并视频交付，以及480P/720P参数。模型组配图不包含接入提示文字，仍与当前模型/Key布局相符；其余配图操作仍适用。正文与配图无版本更新或发布记录，PDF同步，价格参考资料仅留本地。
