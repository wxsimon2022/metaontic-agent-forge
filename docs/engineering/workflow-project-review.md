# 项目审核与制作流程

需求阶段由 metaontic_agent_forge_video_project.prepare 创建项目并提前取得角色图路线；无固定主体空镜跳过提问，改提示词、时长或清晰度不重问角色图。记录保存在 DSH_HOME/metaontic-agent-forge/projects，以会话身份校验、UUID和原子写入保护，内容不含密钥。

完整脚本正文和当前分镜图必须在当轮正文展示，review直接取得宿主真实答复，拒绝/取消/pending不授予审核。审核绑定脚本字节摘要、完整制作参数、模型与渠道；生成前和审批后执行前均核验，审核后不再改写script.md中的状态。脚本/参数改变须重审；旧已提交任务查询及交付恢复保持可用，旧断点只能沿原参数继续。

视频工具审批承担开始制作确认，不另弹同意制作。审批包含模型、画幅、清晰度、音频、本段时长、本段与剩余计划基础估价，手填密钥不默认优惠倍率，未知模型/画幅/输入时长不猜价。

暂停默认只下载并交付新段，最终完整合并。可选累计预览只传resume+cumulativePreview:true，不提交下一段，也不改变原deliveryPending。原始分段永久保留，下载/合并失败不重新生成。

动态创作提示词仅当前视频创作助手模式注入。宿主agentPresets.presetForSession是权威值，标准模式null不回退历史header；旧宿主无registry时只识别明确创建预设。普通标准模式审核提问不经过视频分镜守卫；主动调用视频工具时仍须遵守视频审核与付费确认。

验证：本机TypeScript构建、339项自动测试、宿主原始output JSON Schema校验通过；包含真实插件入口的项目审核、跨模块持久化、配置/脚本变化、取消、角色图选择、累计预览无新增POST、标准模式作用域。低层生成/恢复fixture独立验证原防重与断点逻辑。未发起真实付费API；未做Windows及macOS Harness桌面完整制作实测。项目路径使用node:path和系统用户目录，私有文件使用原子替换；Windows文件占用错误保留原文件并报错。

测试包通过pack-test独立通道提供，不创建正式Release或标签，不改变正式版本与releaseNotes。用户说明书及PDF已同步。
