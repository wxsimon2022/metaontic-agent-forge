# v3.14.0 发布核对

实际基线：v3.13.16。

MetaOnticVideo v3.14.0

新增
- 接入方式新增服务端方式的临时下架开关，当前为下架状态：新装默认 MetaOntic AI，设置页与在线安装都不再提供该方式，恢复时改一个开关即可，其余代码无需改动。

优化
- 接入方式下拉精简为 MetaOntic AI 与火山引擎直连两项，并去掉名称前的 A/B 字母标记，选项文字改为「MetaOntic AI」「MetaOnticVideo」「火山引擎直连」。
- 已配置服务端方式的安装不会显示空白或错位：下拉里该项显示为「MetaOnticVideo（暂时不可用）」并给出切换提示，原有 Key、额度与设备凭据保留；服务端登录表单、额度卡片与充值入口不再显示，后台也不再请求服务端额度与记录接口。

修复
- 服务端方式下架期间，视频生成、续拍、图片处理（含真人参考图转换）与费用查询都会在发出请求前明确拒绝，并提示改用 MetaOntic AI 或火山引擎直连，不再带着旧 Key 调用上游；用配置工具把接入方式保存成该方式同样会被拒绝。

验证
- 本地构建及测试通过。
- 本条按仅 Gitee 发布处理：未运行 GitHub 双平台 CI，也没做 Windows 桌面实测，Windows 兼容性只有构建与打包层面的保证。
- 桌面GUI与付费调用未由发布脚本自动验证。

指南核对：逐项核对使用说明书：接入方式相关章节（第 2、3 节）只保留 MetaOntic AI 的办理与填写步骤，与设置页现在只提供 MetaOntic AI、火山引擎直连一致；删除「服务端登录表单位于接入方式下方」的过时描述，改为说明下拉只有两项、重置入口仍在设置页底部；故障排查、保存与密钥说明、费用与额度说明逐条复核，未出现服务端领 Key 仍可选的表述；配图 install.svg、models-shared.png、models-separate.png、advanced.png、session.svg、creation.svg 均为安装、模型配置、更多设置与流程截图，不含接入方式下拉与服务端登录区，无需重绘；成品安装地址两处已同步为 v3.14.0；Markdown 与 PDF 同步重新生成，指南中不含版本号、更新日志与发布核对记录。
