# v3.13.2 发布核对

适用版本：v3.13.2正式版。范围：v3.13.1之后全部改动。

MetaOnticVideo v3.13.2

修复
- 立即更新前读取真实安装来源，本地目录链接安装停止直接替换，避免触发外部目录异常；不卸载、不清目录、不重置Key。
- 安装来源无法核实、查询失败或元信息异常时停止更新，不继续调用安装器。

优化
- tgz成品及仓库安装保留在线更新入口；补充本地目录用户的恢复与迁移限制说明。
- 双平台发布检查增加真实成品包升级，验证语言资源、原安装文件、配置与任务记录；增加目录链接与异常来源回归测试。

验证
- 构建、249项模拟测试与实际Harness Schema校验通过。
- 双平台发布门槛验证成品安装及真实成品升级、中文空格路径、语言资源、配置/任务保留与入口加载。
- 本地目录保护覆盖Windows盘符、UNC、file/link及Mac绝对路径；回归确认未调用安装器且原文件保留。
- 未进行真实Windows桌面本地目录迁移或付费调用；已变空目录仍需恢复，不承诺来源检查可自动修复历史损坏。

用户明确复现点击立即更新后原package目录变空。此前3.13.1双平台自动检查仅验证首次成品安装，不能证明本地目录迁移正确。Mac复现pnpm更改依赖记录后仍解析旧链接；Windows清空的宿主细节尚未证实。本次通过来源预检阻止危险目录直接更新，非自动修复/迁移。成品升级采用真实pnpm，旧fixture版本0.0.0到当前成品；保留哨兵配置和任务，不调用真实API。指南MD/PDF已同步更新限制，未加入发布记录；价格参考资料不入包。
