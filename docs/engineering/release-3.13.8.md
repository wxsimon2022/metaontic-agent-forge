# v3.13.8 发布核对

实际基线：v3.13.7。

MetaOnticVideo v3.13.8

优化
- 费用预估里的“火山官方方案”统一按 Seedance 2.5 计算，一段按 30 秒计，不足 30 秒的尾段也按 30 秒计，不再按剩余秒数折半；超过 30 秒如实按分段列出。
- 使用说明书里的成品下载地址更新为本版本，Gitee 与 GitHub 两条 .tgz 地址可直接复制粘贴安装。
- 发布流程新增校验，使用说明书里的成品地址必须与本次发布版本一致，不一致直接失败，避免指南长期指向旧版本。

修复
- 多段视频交付时合并成片没有排在第一个位置的问题；现在成片固定排在最前，助手若把分段放在成片前面，插件会拦下这次展示并让他把成片挪到第一位重发，不会因此少给成片或分段。

验证
- 本地构建及测试通过。
- Windows/macOS成品安装及升级为CI上传前置条件。
- 桌面GUI与付费调用未由发布脚本自动验证。

指南核对：本次改动涉及交付顺序与费用预估口径：使用说明书“结果保存与常见问题”一节补充成片卡片排在最前、助手把分段放在成片前面时会被拦下并把成片挪到第一位重发；创作流程的费用预估一条补充火山官方方案按 Seedance 2.5、一段 30 秒计算（不足 30 秒的尾段也按 30 秒，不折半）；1.3 与 1.4 安装一节的成品地址更新为本版本。其余配置项、操作步骤、默认行为及常见问题逐条核对后无变化；指南不含版本号、更新日志与发布核对记录，Markdown 与重新导出的 PDF 内容一致并随包发布。
