# 3.10.0-beta.2 发布核对

MetaOnticVideo v3.10.0-beta.2（预发布）

修复
- 移除公共插件对 Hyperframes、esbuild 等构建工具的运行依赖，避免在线更新因安装脚本被拦截而报错。

优化
- 在线更新改为安装所选版本的 Release 成品包，Gitee 附件不可用时尝试同版 GitHub 附件，不回退旧版或开发分支。
- 内部 Hyperframes 仅保留为开发依赖，公开视频生成和实际费用查询无需批准额外构建脚本；同步使用说明书与 PDF。

验证
- 构建、142 项测试与实际 Harness 的 8 个工具输出 Schema 校验通过。
- 使用与 App 相同的 pnpm 在独立目录严格拦截安装脚本验证，成品包安装成功，运行依赖不含 Hyperframes/esbuild。
- 使用说明书 Markdown/PDF 已同步纳入包，价格参考资料仍仅留本地；未发起付费生成。

适用版本：3.10.0-beta.2。指南逐项复核安装、Key、保存、渠道切换及制作恢复；补充成品包更新无需构建脚本授权，已有配图与操作步骤仍适用。正文和配图无版本更新内容，PDF 同步。
