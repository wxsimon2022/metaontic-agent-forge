# v3.13.12 发布核对

实际基线：v3.13.11。

MetaOnticVideo v3.13.12

优化
- 脚本设计阶段的耗时统计改由插件自动结束——完整脚本保存为 script.md 后自动闭合该段计时并写入 script_saved 日志，不再依赖模型手动调用结束，阶段耗时统计更准确；脚本不是用写文件工具保存时仍按原方式补结束。
- 新增维护者清理命令 npm run clean:releases（默认只演练），按同一份计划回收两个仓库的历史标签、发行版与发行版附件，最新正式版始终保留；并配套每周演练工作流，只有确认后才真正删除。

修复
- 发布时 Gitee 上传成品包偶发 HTTP 400 会让整次发布中断；现在失败会带出服务端返回正文，先复查附件表是否已收完，再按退避自动重试，减少人工重跑。

验证
- 本地构建及测试通过。
- Windows/macOS成品安装及升级为CI上传前置条件。
- 桌面GUI与付费调用未由发布脚本自动验证。

指南核对：本次只把 1.3 节写死的 Gitee 与 GitHub 两条成品地址同步到本版本，并复核周边说明。1.3 节 Windows 安装步骤、ZIP 资料包用法、安装框该填 .tgz 文件的提示，1.4 节 Mac 本地安装，在线更新与故障排查表逐条核对，均与上一版一致、无行为变化；指南不含版本号、适用版本、更新日志与发布核对记录。正文修改后已重新导出 PDF，Markdown 与 PDF 内容一致并随包发布。
