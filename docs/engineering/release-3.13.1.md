# v3.13.1 发布核对

适用版本：v3.13.1正式版。范围：v3.13.0之后全部改动。

MetaOnticVideo v3.13.1

修复
- Windows安装资料ZIP内置原始tgz，改为安装成品文件，由安装器管理插件文件，减少对外部解压目录的依赖。

优化
- 补充旧安装目录变空、locale缺失的完整目录恢复步骤，保留Key、配置及任务记录，不先卸载或重置。

新增
- 建立Windows/macOS兼容开发规范，发布前自动在双平台验证成品安装、中文空格路径、语言资源、技能、指南及源文件移走后的加载。

验证
- 构建、226项模拟测试、实际Harness Schema/Config和元信息读取验证通过。
- 双平台成品安装检查作为Release上传前置条件；覆盖中文空格路径、locale和安装源移走后的入口加载。
- ZIP原始tgz及全部文件校验、重复打包一致性与SHA-256核对通过。
- 未进行真实Windows桌面更新操作或付费生成；未证实旧目录被清空的具体原因。

指南核对Windows本地tgz安装、旧目录恢复与配置保留；7张配图核对并同步PDF，指南不加入版本或发布日志。Mac保留仓库方式。开发规范纳入AGENTS和维护经验。Windows/macOS runner采用同一成品；自动结果需发布后核对，不宣称桌面实机更新通过。价格参考资料不入仓库或附件。
